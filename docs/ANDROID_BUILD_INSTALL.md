# Сборка и установка на физический Android-телефон (Windows)

Эта инструкция предназначена для локальной сборки Retro Mobile World с экспериментальным Nokia C3-00 / RM-614 backend и установки APK на подключённый физический телефон. Она не использует Android Emulator.

## Требования

- Windows PowerShell 5.1 или PowerShell 7;
- Git;
- JDK 17;
- Android SDK Platform 36 и Build Tools 36.0.0;
- Android NDK 27.2.12479018;
- стабильный Rust toolchain через rustup;
- подключённый Android-телефон и исправный USB-кабель.

Сценарий сборки ищет SDK в ANDROID_SDK_ROOT, ANDROID_HOME, local.properties, D:\Android\Sdk и стандартных папках Windows. Для этой рабочей станции подтверждён путь D:\Android\Sdk.

## Включить режим разработчика на телефоне

Это действие выполняется на самом телефоне. ADB не включает скрытое меню Developer options на обычном, не-root Android-устройстве.

1. Откройте **Настройки → О телефоне**.
2. Найдите **Номер сборки** (на некоторых оболочках — **Версия MIUI**) и нажмите семь раз, пока телефон не подтвердит включение режима разработчика.
3. Откройте **Настройки → Система → Для разработчиков** (на Xiaomi/MIUI обычно **Расширенные настройки → Для разработчиков**).
4. Включите **Отладка по USB**.
5. Подключите телефон к ПК, разблокируйте экран и подтвердите запрос **Разрешить отладку по USB** для этого компьютера. При необходимости выберите «Всегда разрешать с этого компьютера».
6. На некоторых Xiaomi также требуется включить **Установка через USB** в параметрах разработчика. Это отдельный пункт оболочки производителя; включайте его только если обычный adb install сообщает об ограничении установки.

## Одна команда: обновить, собрать, протестировать и установить на телефон

Из корня локального репозитория:

```powershell
.\scripts\build-install-c3emu-phone.ps1
```

Сценарий:
- сначала проверяет чистоту рабочего дерева; при локальных изменениях останавливается и ничего не стирает;
- получает целевую ветку feature/c3emu-touch-shell-speed-20261107 и обновляет её только через fast-forward;
- безопасно переключается на целевую ветку только при чистом рабочем дереве;
- определяет Android SDK и NDK;
- собирает нативный C3-00 backend для arm64-v8a, armeabi-v7a и x86_64;
- выполняет :app:testDebugUnitTest и :app:assembleDebug;
- показывает подключённые устройства и исключает serial эмуляторов emulator-*;
- при единственном авторизованном физическом телефоне выбирает его; при нескольких требует явный -Serial;
- устанавливает локально собранный app-debug.apk через adb -s <serial> install -r и запускает org.retromobile.world.

Сценарий не вызывает adb -e, не устанавливает APK в Android Emulator и не применяет git reset, git clean, stash или force push.

## Если подключено несколько телефонов

Сначала посмотрите serial:

```powershell
& 'D:\Android\Sdk\platform-tools\adb.exe' devices -l
```

Запустите сборку для нужного физического телефона, подставив его serial:

```powershell
.\scripts\build-install-c3emu-phone.ps1 -Serial 'SERIAL_ТЕЛЕФОНА'
```

Serial вида emulator-5554 для этого сценария запрещён.

## Проверка ADB отдельно

Убедитесь, что ADB видит именно физический телефон в состоянии device:

```powershell
$Adb = 'D:\Android\Sdk\platform-tools\adb.exe'
& $Adb version
& $Adb devices -l
```

Варианты состояний:
- device — телефон авторизован и готов;
- unauthorized — разблокируйте телефон и подтвердите RSA-запрос отладки;
- offline — переподключите USB, смените USB-порт/кабель и повторите adb devices;
- список пуст — проверьте режим передачи данных USB и включение USB debugging.

## Результат и следующий функциональный тест

Локальный APK находится здесь:

app\build\outputs\apk\debug\app-debug.apk

После запуска откройте отдельный пункт **Nokia C3-00 · Open emulator**, импортируйте собственный Phoenix ZIP для RM-614 и попробуйте запустить Series 40. Запишите точный текст результата импорта/загрузки. Успешная установка приложения ещё не означает, что гостевая прошивка загрузилась: подтверждение boot — реальный кадр LCD от Series 40 и реакция на клавиши.

RM-217 / Nokia 6300 использует отдельную ветку исследования и не должен запускаться через C3-00 backend.
